## 🚀 My Main Projects

If you find any of these useful, a ⭐ on GitHub is always welcome.

### Teaching

- **[`fp`](https://github.com/joapuiib/fp)**: Notes and resources for the vocational training (FP) subjects I teach.
- **[`curs-git`](https://github.com/joapuiib/curs-git)**: Teacher training course *Introduction to Git and GitHub Actions*, offered by the [CEFIRE](https://aules.edu.gva.es/autoformacio/course/view.php?id=591), with materials for using Git in the classroom.

### MkDocs tooling

- **[`mkdocs-material-joapuiib`](https://github.com/joapuiib/mkdocs-material-joapuiib)**: Theme for course materials, built on [`mkdocs-materialx`](https://github.com/jaywhj/mkdocs-materialx) and published on [PyPI](https://pypi.org/project/mkdocs-material-joapuiib/). Adds cover pages, [Reveal.js](https://revealjs.com/) slides, extra admonitions, KaTeX and Git console highlighting.
- **[`mkdocs-data-plugin`](https://github.com/joapuiib/mkdocs-data-plugin)**: MkDocs/ProperDocs plugin that loads data from YAML and JSON files so you can use it in your Markdown pages.
- **[`pymdownx-inline-blocks`](https://github.com/joapuiib/pymdownx-inline-blocks)**: Python Markdown extension that turns one-line shorthand into full [PyMdown Blocks](https://facelessuser.github.io/pymdown-extensions/extensions/blocks/) syntax, e.g. for image captions and attributions.
- **[`pygments-shell-console`](https://github.com/joapuiib/pygments-shell-console)**: Pygments lexers that highlight shell console sessions: prompt (user, host, directory, git branch) and `git` command output.
